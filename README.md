# 🌟 UNY-WEB

> The informational landing page and pre-launch hub for the Uny campus-life ecosystem.

Uny Web is designed to build anticipation and capture early interest. The site focuses entirely on marketing the upcoming Uny mobile product and seamlessly onboarding early adopters.

---

## ✨ Core Capabilities

*   📝 **Waitlist Management**
    A streamlined registration system that captures user interest, allowing students and organizers to sign up for early access and future updates.

*   📱 **Product Education**
    Comprehensive overviews of Uny’s core mobile features, highlighting the value of campus networking, event discovery, free passes, and seamless QR code check-ins.

*   🎨 **Brand Presence**
    Establishes the visual identity, tone, and core value proposition of the Uny ecosystem ahead of the official mobile launch.
